## ✨ Features & Architecture

1. **Occasion-Led Catalog:**
   - Visual milestone showcase covering Birthday Celebrations, Multi-Tier Wedding Centerpieces, Korean-Style Bento Boxes, Romantic Anniversaries, Corporate Events, and Baby Showers.
2. **Interactive WhatsApp Order Enquiry Engine:**
   - Step-by-step custom order configuration with live pricing estimates in Nigerian Naira (₦).
   - Real-time calculations for occasion types, cake sizing/servings, gourmet flavour profiles, delivery destination zones, and celebration add-ons.
   - Generates structured, readable order requests dispatched directly into WhatsApp.
3. **Verified Delivery History:**
   - Authentic studio photography of completed orders with delivery status badges.
   - One-click *"Order Similar Style"* pre-fill integration.
4. **Finished Cakes Video Showcase:**
   - HTML5 video players showcasing 360-degree finished cake reveals.
5. **Interactive Google Maps Embed:**
   - Embedded Google Maps card highlighting the Oyigbo studio location with external map navigation support.
6. **Mobile-First & Accessible:**
   - Slide-in navigation drawer for mobile screens.
   - Sticky header with dynamic scroll shadow.
   - High contrast ratios, WCAG compliance, allergen safety disclosures, and SEO metadata.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/Learnuel1/sommycake.git

# Navigate into the folder
cd sommycake

# Open with your browser
# (Windows)
start index.html
# (macOS)
open index.html
# (Linux)
xdg-open index.html
```
